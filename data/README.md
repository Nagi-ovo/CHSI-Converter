# University name dictionary

582 exact Chinese → English mappings derived from [xioajiumi/Chinese_Universities](https://github.com/xioajiumi/Chinese_Universities), commit `e088fddc329a6f0148ca72fd3b4d0fe069f13e3a`, CSV fields `name` and `name_eng`. The source describes its data as the 2021 ShanghaiRanking university list. Retrieved 2026-10-13; MIT license retained in LICENSE.

This is a community dataset, not a complete national register or a certification of every English name. Unknown institution names remain unchanged; do not use fuzzy matches, auto-translation, or silently substitute renamed schools. Historical names can remain valid on historical reports. Correct entries against each institution’s official English website and record the source before updating.
